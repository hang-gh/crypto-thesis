# crypto-thesis

Relative valuation tracker. Inside each of Money (BTC, ZEC, Pearl), Issuing (ETH, SOL, SUI, NEAR), and Trading (BNB, HYPE, LIT, and unlisted VAR), every member can be valued against every other member by FDV.
